# Review checklist

- Valid large sets can start and be saved.
- Missing or invalid answers are blocked with exact question numbers.
- Paired import recognizes the questions and answers files in either selection order.
- Backup contains every known BlueQuiz storage key.
- Restore rejects unrelated JSON before changing storage.
- TXT, Excel, and Word features remain available without network access.
- Desktop and mobile layouts do not clip saved-quiz actions or status messages.
